beautiful and intutive lead generator for your new job

backend set up procedure:
1. open google sheet and create a new sheet
2. from the URL tab on top copy the sheet id as explained you will need this later
      example if this is the url: https://docs.google.com/spreadsheets/d/17xOA-qkxWjb3Q4j3MkoiLcI1gxZurwRT7c7xqtW4tFE/edit?gid=0#gid=0
      copy the portion between /d and /edit that is 17xOA-qkxWjb3Q4j3MkoiLcI1gxZurwRT7c7xqtW4tFE
3. go to extension tab on google sheet and select Apps Script
4. copy the code from test.gs file and paste it here
5. replace the sheet id as indicated in comment
6. click deploy -> new deployment
7. give some name and modify "who has access" to "Anyone"... VERY IMPORTANT STEP
8. click on deploy and copy the web app URL as shown... save it you will need it later
      it looks somewhat like this: https://script.google.com/macros/s/AKfycbyQ7gtAmbVbzIPO9E5WvHxSSyqd5SWcQf-gppiQEgAH/dev
9. go to background.js file and modify the APP_SCRIPT_URL with your own web app url you just made
10. Voila! you have completed the one time setup and good to go now!
